# YuWMS 本地版

这是基于当前目录旧 WMS 资料拆解后重做的一套轻量 WMS。它不依赖旧 Windows 客户端，后端使用 Python 标准库 + SQLite，前端是本地 Web 控制台。

## 旧资料分析结论

- `WMS client/CLIENT0427/FormConfig` 里能看到原系统核心表单：`InstockInformList`、`InStockTbl`、`OutstockInformList`、`OutStockPickDt`、`MoveEntryList`、`InventoryQry_c`、`StockChkDtTbl`、`StcAdjustList`。
- `RMR_SOP_013 原料WMS系统标准操作程序.docx` 说明了实际操作链路：入库通知、收货、SSCC 标签、RF 上架、移库、出库通知、波次/分拣、投料确认、返品入库、盘点调整、属性变更。
- `WMS操作指南` 里的文件名补充了现场场景：退货入库、补货退单、库存调整、库位查询、成品/颗粒盘点、手持验货、手持移库、手持上架。

## 新系统已实现

- 账户登录：所有业务 API 需要登录，会话通过 HttpOnly Cookie 保存。
- 角色权限：系统管理员、仓库主管、原料仓操作、成品仓操作、只读查看。
- 服务端拦截：入库、出库、成品、移库、盘点、属性变更、主数据、重置等接口都按角色校验。
- 操作留痕：库存流水会记录登录操作人。
- 入库上架：创建入库单、生成 SSCC、写入库存和流水。
- 出库分配：按库位优先级、BBD、SSCC 顺序分配；欠品单不允许确认。
- 出库确认：确认后真实扣减库存，保留量清零。
- 移库：支持整托移库和部分移库，部分移库会生成拆分 SSCC。
- 盘点调整：记录系统数、实盘数、差异数，并同步库存。
- 属性变更：支持合格、待检、暂扣、隔离、冻结；暂扣库存不参与出库/发料分配。
- 主数据：货品、库位可新增或更新。
- 查询与台账：库存明细、出入库单、移库单、盘点单、库存流水。
- 分层导航：入库、出库、包材、成品、备件等模块在左侧展开子菜单，只显示当前子功能，避免一个页面堆满所有操作。
- 智能中心：汇总安全库存、临期、欠品、暂扣/冻结、盘点差异和波次进度风险；支持智能生成成品波次和动态安全库存建议。
- 安全库存与临期提醒：货品可设置最低库存、安全库存、临期提前提醒天数；库存页和总览页自动生成预警清单。
- 包材 WMS：包材入库验收、包材领用发料、暂扣/放行、库存查询、安全库存预警、临期提醒、包材出入库导入导出。
- 成品 WMS：成品完工入库、成品库存、客户发货通知、波次创建、多订单合并拣货、订单复核、装车发货、成品安全库存和成品近效期预警。
- TMS 运输执行：成品发货后自动生成运输单，支持控制塔、承运商线路、发车、在途温控、IoT/GPS 遥测、司机任务、POD 签收、独立运费账单、ERP/MES/QMS/OMS/IoT 接口日志、审计证据包、承运商绩效、渠道最小剩余效期和批次召回定位。
- Excel 导入导出：支持库存、成品库存、包材库存、主数据、入库单、出库单、库存流水、TMS 运单、在途/温控事件、IoT/GPS 遥测、司机任务、POD、运费账单、承运商绩效、接口日志、审计证据包、渠道效期规则和召回记录导出；支持货品、库位、入库、出库、成品完工入库、成品客户发运、包材入库、包材领用按模板批量导入。
- 设备部备品备件：备件基础台账、入库验收、维修工单领用、旧件退库、盘点调整、旧件报废、库存预警、食品接触件清场确认、高价值/关键件审批。

## 启动

双击：

```text
start_yuwms.command
```

或在终端启动：

```bash
cd modern_wms
python3 app.py
```

打开：

```text
http://127.0.0.1:8765
```

如果 `8765` 已经被占用，系统会自动尝试 `8766`、`8767` 等后续端口，并在终端打印实际地址。

## 智能中心

登录后进入左侧 `智能` 模块：

- `预警中心`：把安全库存、临期、欠品、暂扣/冻结/隔离、盘点差异、波次进度合并成风险清单，按高/中/低风险排序，并给出建议动作。
- `查询助手`：用自然语言查询库存、临期、暂扣/冻结、欠品、发货进度、盘点差异和动态安全库存建议；答案只基于当前账套数据。
- `SOP助手`：输入“成品发货怎么做”“包材暂扣怎么放行”“盘点差异怎么处理”等问题，系统返回步骤、检查点和下一步入口。
- `智能波次`：按同月台、同线路、同 SKU 聚合待发成品订单，一键生成成品拣货波次，减少重复拣货和现场走动。
- `安全库存`：按近 30 天出库、供应周期和安全缓冲计算建议安全库存；`admin/supervisor` 可一键应用到货品主数据。

## 包材 WMS

登录后进入左侧 `包材` 模块：

- `包材入库`：选择包材 SKU、供应商批次、采购单号、包材库位和品质状态；可直接选择 `暂扣`。
- `包材领用`：按包装线、返工换包、试产打样等去向生成领用单，系统只分配 `合格` 库存。
- `暂扣/放行`：包材库存表支持快速暂扣和放行；暂扣批次会保留在库存中，但不会参与领用分配。
- `包材安全库存`：按最低库存、安全库存生成预警和建议补足数量。
- `包材临期提醒`：按货品主数据里的临期提前提醒天数显示临期/过期批次。

## 成品波次发货

登录后进入左侧 `成品` 模块，按子菜单操作：

- `发货通知`：录入客户订单、SKU、数量、渠道编码和装车口，系统按渠道最小剩余效期、BBD 和库位优先级分配可发库存；不满足渠道效期会进入 `效期不足` 状态并禁止确认。
- `波次创建`：可手工输入多张发货单，也可按待拣货订单创建一个成品波次。
- `合并拣货`：系统按 SKU、SSCC、库位汇总不同订单的拣货量，现场按托盘/批次一次拣货。
- `订单复核`：拣货完成后按客户订单拆分复核，记录暂存区、复核人和备注。
- `装车发货`：复核后登记车牌、司机、封签和月台，确认后真实扣减库存并完成波次。

## TMS 运输执行

TMS 已整合在原 YuWMS 左侧导航 `TMS运输` 中，不再单独启动新程序。

- `运输计划`：从 WMS 成品发货单生成运输单；成品直接发货或波次装车确认后也会自动生成 TMS 运单。
- `在途温控`：记录发车、到达、温度、湿度、开门、GPS/位置备注等事件；超出线路温控范围会自动标记运输异常。
- `控制塔`：集中显示活跃运输、异常、IoT 高风险、司机待办、接口待办和运费差异。
- `IoT/GPS`：接收车载温控、GPS、门磁、冷机状态和速度；超温或在途开门自动进入风险队列。
- `POD/运费`：记录客户签收、破损、短少和备注；`admin/supervisor/tms` 可做运费对账。
- `司机协同`：自动生成司机任务，支持接单、发车、到达和签收状态回传。
- `外部接口`：模拟 OMS 订单、ERP 运费、MES/QMS 放行冻结召回、承运商状态和 IoT 遥测接入，并保留接口日志。
- `审计包`：按运输单或批次生成审计证据包，打包运单、批次、事件、遥测、POD、运费和司机任务。
- `召回追溯`：按 GoodsID + 批号定位在库 SSCC 和已发运 TMS 运单，便于宠物食品批次召回。
- `承运商绩效`：按承运商汇总运单数、OTIF、POD率、温控异常率、费用偏差率和综合评分。
- `承运商线路`：维护承运商、服务类型、冷链能力、线路时效、温控上下限、基础费率和渠道效期规则。

## 设备部备品备件

登录后进入左侧 `备件` 模块：

- `备件基础台账`：编码、规格、品牌、ABC等级、最低/安全/最高库存、采购周期、单价、供应商、货位、适用设备、食品接触件、进口件、关键备件。
- `备件入库`：记录采购单/供应商/验收人/库管员/货位，自动增加库存和流水。
- `工单领用`：必须填写维修工单、设备、领用人；关键件或高价值件必须填审批人；食品接触件必须勾选维修后清场确认。
- `旧件退库/报废`：记录旧件状态、审批人、报废原因，形成追溯流水。
- `备件盘点`：按实盘数量调整库存并记录差异。
- `库存预警`：按当前库存、最低库存、安全库存和关键件状态生成黄色/橙色/红色预警。

## 安全库存与临期提醒

登录 `admin` 或 `supervisor` 后进入左侧 `主数据`：

- `最低库存`：低于该数量会触发红色库存预警。
- `安全库存`：低于该数量但未低于最低库存时，触发黄色预警。
- `临期提前提醒天数`：例如设置为 `60`，则 BBD 距今天 60 天内的批次会进入临期提醒。

进入左侧 `库存` 或 `总览` 可查看：

- `安全库存预警`：显示可用库存、最低库存、安全库存、建议补足数量和预警状态。
- `临期提醒`：显示 SSCC、GoodsID、库位、BBD、剩余天数和临期/过期状态。

## 盘点与系统日志

左侧 `盘点` 已按子菜单拆分：

- `日常盘点`：按 SSCC 录入实盘数量。无差异时仓库账号可记录；有差异并需要调整系统库存时，仅 `admin` 和 `supervisor` 可执行。
- `月度/年度盘点`：按全仓、货品类别、仓库区域或 GoodsID 生成盘点清单。
- `盘点记录`：查看日常、月度、年度盘点记录、差异数量、是否调整、操作人和原因。

左侧 `日志` 仅 `admin` 和 `supervisor` 可见，记录登录、导入、导出、入库、出库、移库、盘点、权限拒绝等系统操作，并支持 Excel 导出。

## RF/扫码、库位推荐和三维库位

左侧 `RF/扫码` 支持：

- RF 枪键盘楔入：扫描后直接回车识别 SSCC、库位码或 GoodsID。
- 二维码/条码摄像头识别：浏览器支持 `BarcodeDetector` 时可调用本机摄像头识别二维码、Code128 等编码。
- 扫描记录：记录来源、动作、识别类型、引用单号/SSCC、库位、货品和操作人。

左侧 `入库` 的 `库位推荐` 会按货品类别、品质状态、库区优先级、库位容量、占用率和同品邻近生成候选库位；`冻结/隔离/待检/暂扣` 状态会优先推荐质量区或暂扣相关库位。

左侧 `三维库位` 支持：

- 根据库位主数据和库存占用实时生成在线三维库位模型。
- 用摄像头采集库位，形成建模采集记录，并把最近采集时间关联到库位模型。
- 显示库位占用率、空闲、高占用、暂扣和需复核状态。

## 原料/产品标签打印

左侧 `标签` 支持：

- `原料标签` 和 `产品标签` 两套模板。
- 人工录入批号、供应商/生产批次、数量、生产日期、BBD、库位、SSCC、品质状态和打印份数。
- 系统自动生成条码值和二维码值；条码使用 Code128，适配常见 RF 枪/扫码枪。
- 生成后可预览标签，并点击 `连接打印机打印` 调用系统打印对话框，选择已连接的标签打印机。
- 每次生成都会写入 `标签打印记录`，可在页面查看并通过 Excel 导出。

## Excel 导入导出

登录后进入左侧 `Excel` 模块：

- `导出当前数据`：下载 `.xlsx` 文件，包含库存明细、成品库存、包材库存、货品主数据、库位主数据、入库单、出库单、库存流水、标签打印记录、安全库存预警、临期提醒；`admin/supervisor` 还可导出系统操作日志。
- 包材可导出：包材库存、包材库存预警。
- 设备备件可导出：备件基础台账、备件出入库流水、备件库存预警。
- TMS 可导出：TMS 运输单、在途/温控事件、IoT/GPS 遥测、司机任务、POD 签收记录、运费账单、承运商绩效、接口日志、审计证据包、渠道效期规则、批次召回记录。
- `下载导入模板`：按当前账号权限显示模板。
- `批量导入`：支持 `.xlsx` 和 `.csv`，导入时会按登录账号校验权限并写入库存流水。

导入权限：

```text
admin / supervisor：货品、库位、入库、出库、成品入库、成品发运
pkg：包材入库、包材领用
equip：admin/supervisor 外的设备部专用账号，可导入备件台账、备件入库、备件领用
raw：入库、出库
fg：成品入库、成品发运
view：只能导出，不能导入
```
